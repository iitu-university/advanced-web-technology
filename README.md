# Advanced Web Technologies

The numbered directories preserve the progression of the course project. Labs 6–9 use the six-course catalog introduced by the FastAPI backend in Labs 4–5.

| Directory | Work |
|---|---|
| `01-github-explorer` | HTML/CSS/JavaScript GitHub repository search, filtering and local storage |
| `02-course-catalog` | Next.js App Router, typed local data, server/client components and dynamic course routes |
| `03-tailwind` | Responsive catalog with Tailwind and reusable UI components |
| `04-backend` | FastAPI, SQLAlchemy/Alembic, GraphQL and **Lab 9** JWT authentication and authorization |
| `05-integration` | Next.js integration, REST/GraphQL comparison pages and **Lab 9** login and account |
| `06-database` | **Lab 6** PostgreSQL schema, seed, route queries, experiments and report |

For Lab 9, start the [backend](04-backend/README.md#how-to-run) and then the [Next.js frontend](05-integration/README.md#lab-9-login-and-account). The backend README includes the access matrix, open routes, threat table and experiment log.

The [Lab 6 SQL project](06-database/README.md) and the [Lab 7 and 8 backend reports](04-backend/README.md#lab-7-sqlalchemy-and-alembic) record the earlier stages. The handouts describe standalone projects named `course-catalog-db`, `course-catalog-api` and `course-catalog`. This workspace keeps the projects together.
